# inbox —— 材料暂存区

## 用途
把收到的各类成员材料**原样丢进这个文件夹**（Word、照片、txt、导出的聊天记录、邮件内容等，格式不限），
然后告诉助手一句话，例如：

> "inbox 里是张三的简介更新" 或 "inbox 里有两个新成员的材料"

助手会负责：解析材料 → 规整中英双语 → 提取/归档照片 → 写入数据源 → 重新生成页面。

## 约定
- 本目录**只是暂存**，处理完成后材料会被归位：
  - Word 简介 → `member materials/BIRD Lab个人简介-<中文名>.docx`
  - 照片 → `images/people/<slug>.jpeg`
- 因此本目录平时应为空（只保留本说明文件）
- 处理完成后助手会告知归档去向，便于你核对

## 照片建议（可选，能省事）
- 命名不用管，助手会重命名
- 但请尽量给**清晰的正脸照**，长边 ≥ 400px
